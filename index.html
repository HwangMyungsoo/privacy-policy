개인정보 처리방침

Beacon Scanner | 시행일: 2026년 9월 24일 (최초 시행 2026년 3월 6일)

Beacon Scanner는 스캔 데이터를 외부 서버로 전송하지 않습니다.
모든 스캔 데이터는 사용자의 기기 내에서만 처리되며, 앱 종료 시 삭제됩니다. 광고(AdMob)와 원격 설정(Firebase)을 위해 Google 서비스와 통신하는 내용은 1-3, 1-4항을 참고하시기 바랍니다.

1. 수집하는 정보

1-1. 앱이 직접 처리하는 정보

정보 항목 수집 목적 저장 방식
BLE 디바이스 MAC 주소, 디바이스명 비콘 탐지 및 식별 앱 메모리 (앱 종료 시 삭제)
RSSI 신호 강도, TX Power 거리 추정 및 신호 모니터링 앱 메모리 (앱 종료 시 삭제)
비콘 정보 (UUID, Major, Minor) 비콘 프로토콜 식별 앱 메모리 (앱 종료 시 삭제)
즐겨찾기 디바이스 MAC 주소 즐겨찾기 기능 기기 내 저장 (SharedPreferences)

위 정보는 기기 외부로 전송되지 않으며, 사용자의 기기 내에서만 처리됩니다.

1-2. CSV 내보내기

사용자가 직접 "내보내기" 기능을 실행한 경우에만 스캔 로그가 CSV 파일로 기기의 로컬 저장소에 저장됩니다. 이 파일은 외부 서버로 자동 전송되지 않습니다.

1-3. 제3자(Google AdMob)가 수집하는 정보

본 앱은 광고 서비스를 위해 Google AdMob을 사용합니다. AdMob은 다음 정보를 수집할 수 있습니다:

  • 광고 식별자 (Google Advertising ID)
  • 기기 정보 (모델, OS 버전 등)
  • IP 주소
  • 광고 상호작용 데이터 (노출, 클릭)

Google의 데이터 수집 및 처리에 대한 자세한 내용은 Google 개인정보처리방침을 참고하시기 바랍니다.

1-4. 제3자(Google Firebase)가 수집하는 정보

본 앱은 광고 노출 여부 등 앱 설정을 원격으로 제어하기 위해 Google Firebase Remote Config를 사용합니다. 설정을 조회할 때 다음 정보가 Google 서버로 전송될 수 있습니다:

  • Firebase 설치 ID (앱 설치 단위로 생성되는 익명 식별자)
  • 기기 정보 (모델, OS 버전, 언어, 국가)
  • 앱 버전
  • IP 주소

이 정보는 사용자를 개인적으로 식별하는 데 사용되지 않습니다. 자세한 내용은 Firebase 개인정보 보호 및 보안을 참고하시기 바랍니다.

2. 앱 권한

권한 사용 목적
BLUETOOTH_SCAN BLE 비콘 스캔
BLUETOOTH_CONNECT 블루투스 디바이스 정보 접근
ACCESS_FINE_LOCATION Android 요구사항으로 BLE 스캔에 필요 (실제 GPS 위치를 수집하지 않음)
ACCESS_COARSE_LOCATION Android 12 이상에서 ACCESS_FINE_LOCATION과 함께 요청해야 하는 권한 (실제 위치를 수집하지 않음)
INTERNET 광고 로드 (AdMob) 및 원격 설정 조회 (Firebase)

3. 데이터 보관 및 삭제

  • 스캔 데이터: 앱 실행 중 메모리에만 보관, 앱 종료 시 자동 삭제
  • 즐겨찾기: 앱 삭제 시 또는 앱 데이터 초기화 시 삭제
  • CSV 파일: 사용자가 직접 삭제 가능

4. 아동의 개인정보

본 앱은 만 13세 미만의 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

5. 개인정보 처리방침 변경

본 방침은 변경될 수 있으며, 변경 시 앱 업데이트 또는 이 페이지를 통해 고지합니다.

Privacy Policy

Beacon Scanner | Effective Date: September 24, 2026 (originally March 6, 2026)

Beacon Scanner does not transmit your scan data to any external server.
All scan data is processed only on your device and deleted when the app is closed. See sections 1-3 and 1-4 for communication with Google services for ads (AdMob) and remote configuration (Firebase).

1. Information We Collect

1-1. Information Processed by the App

Information Purpose Storage
BLE device MAC address, device name Beacon detection and identification App memory (deleted when app closes)
RSSI signal strength, TX Power Distance estimation and signal monitoring App memory (deleted when app closes)
Beacon data (UUID, Major, Minor) Beacon protocol identification App memory (deleted when app closes)
Favorite device MAC addresses Favorites feature On-device storage (SharedPreferences)

The above information is never transmitted outside your device and is processed locally only.

1-2. CSV Export

Scan logs are saved as CSV files to your device's local storage only when you manually trigger the export function. These files are not automatically uploaded to any server.

1-3. Information Collected by Third Parties (Google AdMob)

This app uses Google AdMob for advertising. AdMob may collect the following information:

  • Advertising identifier (Google Advertising ID)
  • Device information (model, OS version, etc.)
  • IP address
  • Ad interaction data (impressions, clicks)

For details on Google's data collection and processing, please refer to the Google Privacy Policy.

1-4. Information Collected by Third Parties (Google Firebase)

This app uses Google Firebase Remote Config to control app settings remotely, such as whether ads are shown. When fetching configuration, the following information may be sent to Google servers:

  • Firebase installation ID (an anonymous identifier generated per app installation)
  • Device information (model, OS version, language, country)
  • App version
  • IP address

This information is not used to personally identify you. For details, please refer to Privacy and Security in Firebase.

2. App Permissions

Permission Purpose
BLUETOOTH_SCAN BLE beacon scanning
BLUETOOTH_CONNECT Accessing Bluetooth device information
ACCESS_FINE_LOCATION Required by Android for BLE scanning (does not collect actual GPS location)
ACCESS_COARSE_LOCATION Must be requested together with ACCESS_FINE_LOCATION on Android 12 and later (does not collect actual location)
INTERNET Loading ads (AdMob) and fetching remote configuration (Firebase)

3. Data Retention and Deletion

  • Scan data: Stored in memory during app use, automatically deleted when the app closes
  • Favorites: Deleted when the app is uninstalled or app data is cleared
  • CSV files: Can be manually deleted by the user

4. Children's Privacy

This app is not intended for children under the age of 13, and we do not knowingly collect personal information from children.

This policy may be updated. Changes will be communicated through app updates or this page.
